Review Instructions

Work through the images in order and record one answer per image. Please review independently and do not discuss individual images with the other reviewers until everyone has finished.

Target classes

Only these six classes matter for this review:

  • RedOnion_Raw
  • Yam_Raw
  • Tomato_Raw
  • Papaya
  • Potato_Raw
  • Lemon

Other classes may be visible in an image. You do not need to review them.

What to decide

For each image, look at the boxes and labels already drawn on it and decide whether the existing annotation is correct for the six target classes.

  • NO — the annotation looks fine.
  • YES — there is a problem. Record the type, the affected classes and how many separate problems you found.
  • AMBIGUOUS — you genuinely cannot tell. This is a valid and useful answer, so please do not force a guess.

Defect types

MISSING_LABEL
An object of a target class is clearly visible, but it has no box or label.
WRONG_CLASS
There is a box, but the class on it is wrong. This includes both directions: a target class labelled as something else, and something else labelled as one of the target classes.
BBOX_ERROR
The box is clearly in the wrong place, or clearly the wrong size.
GRANULARITY_MISMATCH
The annotation is inconsistent about how objects are grouped — for example, some items of the same kind get one box each while others are covered by a single box around the group.
SPURIOUS_LABEL
There is an annotation where no such object actually exists.
OTHER
A clear annotation problem that does not fit any category above. Please describe it in the notes.

Two kinds of image

The images do not all show the same information. Both kinds are a normal part of this review — there is nothing wrong with the images themselves.

Images showing the current annotation only

These show the existing annotation and nothing else. Check the six target classes and record what you find.

Images that also show model output

Some images additionally show what a detection model predicted, including where the model disagreed with the annotation.

You may use this model output as a hint. It is there to help you, and using it is part of what we are measuring. Please keep three things in mind:

  • The model is not necessarily correct.
  • A disagreement between the model and the annotation is not by itself an annotation error.
  • You decide, by looking at the image yourself.

Check the whole image and the annotation for all six target classes — not only the places the model pointed at.

This is an independent verification

You are checking the annotation itself, on your own. You are not checking anyone else's answers, and you are not being asked to agree or disagree with them.

For each image:

  1. Look at the image and the current GT annotation shown on it.
  2. Decide whether there is an annotation defect involving one of the six target classes.
  3. Do not assume that a model prediction or an earlier reviewer's judgement exists — such information is intentionally not shown to you.
  4. Judge only what you can confirm from the image and the GT currently displayed.
  5. If you cannot determine the correct annotation with reasonable confidence, choose AMBIGUOUS.

Every image in your set shows the current annotation only. Base your decision on what is in front of you, and nothing else.

Timing

The time you spend on each image is measured automatically, so there is nothing to write down. Press Pause whenever you step away; paused time is not counted. If you switch to another tab or window, timing pauses on its own and waits for you to press Resume.

Moving through the review

Once you press Next, that image is final and you cannot return to it. This is deliberate: please do not revise earlier answers after seeing later images.
